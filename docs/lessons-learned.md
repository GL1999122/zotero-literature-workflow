# 实战经验 · Lessons Learned

来源：2026-09「气压顶升（pneumatic / hydraulic jacking）」主题完整跑通的实战案例。
本页沉淀本次工作流中的关键防错要点，供后续调用时规避同类问题。

## 1. 检索阶段

- **直接主题词命中不足时应扩展近邻工艺/应用**：以“气压顶升”为直接主题，在知网/IEEE/Elsevier/Springer 中无 EI 或 SCI JCR Q2+ 命中。
  实破口是把对象域扩展到大跨钢结构、储气柜、桥面、储罐浮顶等充气/液压顶升应用。
- **质量门槛先行确认**：执行前明确「中文需 EI 及以上，SCI 需 JCR Q2 及以上」，避免大样本后发现口径不对。
- **近邻工艺作兜底**：当目标工艺自身门槛放不开时，退而求其次收录其上游工艺（顶升/提升/顶推/吊装）的 SCI 一区候选，并在报告中标注相关性降级。

## 2. 分类 / 分档

- 建议按相关度分档归档：**A 档（目标工艺核心）/ B 档（工艺直接相关）/ C 档（应用监测、力学评估等外围）**，目录如 `候选PDF\A|B|C`。
- 同步维护一张「清单/状态表」，逐篇标注 是否下载 / 是否入库 / 是否精读 / 是否已引用于现状分析，避免重复与遗漏。

## 3. 下载阶段（浏览器自动化）

- **动态检测下载目录**：不要假设默认 `Downloads`，实际可能被重定向到 `F:\BaiduNetdiskDownload` 等路径，先确认真实落盘位置。
- **严格去重**：浏览器自动化易产生 `xxx (n).pdf` 重复文件；下载后按 SHA-256 或文件名清理，避免一稿多存。
- **MDPI 反爬（Cloudflare 403）**：先访问文章页建立会话 Cookie，再触发 `/pdf?version=xxx` 下载，可绕开直接请求 PDF 的 403。
- **ScienceDirect**：内嵌 PDF 会被拦；用 `?download=true` 或 `pdfft` 端点，必要时改 `Content-Disposition: attachment`。
- **Hindawi / 部分 SEI 出版社**：Cloudflare 反爬严重，OA 也可能无法自动下载 → 评估后可直接排除，或用机构账号手动接管。
- **遇需登录的界面**：暂停并请用户手动完成机构认证，不要死循环重试。

## 4. Zotero 入库 / 更新

- **写操作偶发断连**：曾出现 `WinError 10054`（远端强制关闭）与 SSL 握手超时；**失败条目重试即可**，不要当成整体失败。
- **API 连接被拒时的回退**：若 MCP 条目写入被拒（如 `WinError 10061`），降级交付**离线 BibTeX**（经 CrossRef DOI 解析批量生成）供手动导入，不影响交付。
- **附件需可读才能做全文处理**：link 型附件无法提取全文；将 PDF 复制进 Zotero storage 目录并重新挂载后，才能用 `zotero_get_item_fulltext` 精读。
- **大 PDF 上传超时**：分批、重试；系统会识别已有附件避免重复上传。
- **条目归属**：条目放入父集合不一定在父集合列表可见——真正的归类在子集合，勿把“父集合为空”误判为“未入库”。

## 5. 精读与中文摘要（提升交付价值）

- 对关键条目用 `zotero_get_item_fulltext` / `zotero_read_pdf_pages` 提取摘要与引言，沉淀真实数据。
- 为每条写**规范短标题 + 中文精读摘要**，并补录到 Zotero 的 `short_title` 与 `abstract` 字段，方便库内直接查阅。
- 中文摘要务必「真实、规范」：保留原文方法与结果数值，不臆测、不改写事实。

## 6. 研究现状与空白分析

- **先聚类再综述**：按研究方向/关键词把已读文献分组，逐方向梳理演进脉络、代表方法与关键结论。
- **现状必须引文**：每一条“已有人做到了 X”都要挂具体文献（作者+年份），确保可溯源、可复核。
- **空白不臆造**：只有基于已读文献才能判断“某方面尚未被覆盖”；对未穷尽检索的方向，用“未见/公开文献较少，需进一步检索”这类限定表述，而非断言无人研究。
- **输出结构化**：`研究现状综述 → 研究空白清单 → 潜在选题方向`，直接可作综述/开题/立项素材。

## 7. 产物管理

- 遵循**核心交付物 + 删中间产物**原则：只保留核心交付物（精读摘要报告、研究现状与空白报告、定稿 BibTeX、PDF），完工后删除过程性报告/早期 BIB，降低维护与 token 成本。

- [ ] 真实下载目录是否已探测确认？
