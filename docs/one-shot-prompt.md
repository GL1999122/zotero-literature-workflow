# 单次工作流提示词（可复用模板）
新开 TRAE 项目时，将下方「模板」中的占位符替换为目标主题即可。

## 通用模板（推荐）
```
请执行完整文献工作流：检索 → 筛选 → 下载 → Zotero 入库 → 分类 → 精读摘要。

【研究对象】<研究主题 / 目标工艺或对象>
【对象域（可选扩展）】<若直接主题命中少，可扩展的近邻工艺或应用，如大跨钢结构、储罐、桥面等>
【关键词集】<搜索关键词，中英文各一组>
【时间范围】<如近 10 年 / 2020 年以来>
【来源库】<如知网、IEEE、Elsevier、Springer、arXiv、MDPI 等>
【质量门槛】<中文：EI 及以上 ｜ SCI：JCR Q2 及以上 ｜ 其他约定>
【数量】<期望收录篇数，如 20 篇>
【精读】<是否需要每篇规范短标题 + 中文精读摘要，并补录 Zotero abstract/short_title 字段>
【产物要求】<核心交付物，如：精读摘要 HTML + 定稿 BibTeX + PDF；完工后删除中间产物>

请严格按顺序执行，每步完成并确认后再进行下一步：
第 0 步 · 环境确认
  确认 Zotero 在运行、Zotero MCP 工具已加载、本机 Chrome 已连接（TRAE Chrome 扩展）。
第 1 步 · 检索
  在指定来源库检索；若直接主题命中不足，扩展到【对象域】后的近邻工艺；输出候选表（标题/作者/年份/来源/DOI/链接）。
第 2 步 · 筛选分档
  按相%关性、质量门槛、可获取性筛选；建议分 A（核心）/ B（直接相关）/ C（外围应用/监测）三档；给出下载清单。
  说明：不限于开放获取，机构订阅可访问的同样纳入。
第 3 步 · 浏览器下载（去重）
  先探测真实下载目录；用本机 Chrome 逐篇下载；每篇展示一次新增文件；遇到：
  - MDPI Cloudflare 403 → 先访问文章页再触发 /pdf?version=xxx
  - ScienceDirect 被拦 → try ?download=true 或 pdfft 端点
  - 需机构登录 → 暂停请用户协助，不强行绕过
  - 某种反爬无法下载 → 说明原因，评估后可能排除，不中断流程
  下载后按 SHA/文件名清理重复文件 `xxx (n).pdf`。
第 4 步 · Zotero 入库
  用 zotero_add_by_doi/url 建条目，zotero_attach_file 挂 PDF。
  写操作若报 WinError 10054 / SSL timeout，仅重试失败条目；若 API 写入被拒（10061），降级交付离线 BibTeX。
  附件若为 link 型读不到全文，把 PDF 复制进 Zotero storage 再挂载。
  完成后打开 Zotero 展示新条目。
第 5 步 · 分类整理
  建父集合 + 按研究方向建子集合；把条目归入对应子集合（注意：父集合可能不在其列表显示，真正的归类看子集合）；按需加标签。
第 6 步 · 精读与中文摘要（若需）
  用 zotero_get_item_fulltext 逐篇提取摘要+引言，据实写规范短标题与中文精读摘要
  （保留真实方法与数值，不臆测），写入 Zotero abstract 与 short_title 字段。
第 7 步 · 同步与交付
  核对条目/附件已入库；生成核心交付物（精读摘要报告 + 定稿 BibTeX），删除中间产物。
```

## 实战示例（“气压顶升”主题）
```
请执行完整文献工作流。
【研究对象】气压顶升（pneumatic / hydraulic jacking）及其充气/液压顶升应用
【对象域】大跨钢结构、储气柜、桥面、储罐浮顶
【关键词】气压顶升法、同步顶升、整体提升；pneumatic jacking, synchronous jacking, integral lifting
【时间范围】中文放宽 10 年；SCI 不限
【来源库】知网、IEEE、Elsevier、Springer、MDPI
【质量门槛】中文 EI 及以上；SCI JCR Q2 及以上
【数量】20 篇
【精读】需要规范短标题 + 中文精读摘要，补录 Zotero
【产物要求】精读摘要 HTML + 定稿 BibTeX + PDF；完工后删除中间产物
```

## 一命令快速版（链路验证）
```
请检索<主题>相关文献，筛<N>篇能获取全文的，用本机 Chrome 下载到工作目录，再用 Zotero MCP 导入并分类。
不限于开放获取，机构订阅可访问的同样纳入；遇需登录页面暂停请我协助；写完下载先去重；入库写失败只重试失败条目。
```
